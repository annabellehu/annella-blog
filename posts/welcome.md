# 欢迎来到我的博客

你好！欢迎来到我的个人博客。这是我使用 Next.js 搭建的第一篇文章。

## 为什么要搭建这个博客？

在信息爆炸的时代，我们每天都在接收大量的信息，但真正属于自己的思考却越来越少。搭建这个博客的初衷，是希望有一个属于自己的空间，记录技术成长、分享学习心得，以及记录生活中的所思所想。

## 技术栈

这个博客使用了以下技术：

- **Next.js** - React 框架，支持静态生成和服务端渲染
- **TypeScript** - 类型安全的 JavaScript 超集
- **Tailwind CSS** - 实用优先的 CSS 框架
- **Markdown** - 简洁的文本标记语言
- **GitHub Pages / Vercel** - 静态网站托管服务

## 特点

### 简约设计

采用极简设计风格，去除一切不必要的装饰，让读者专注于内容本身。

### Markdown 写作

所有文章都使用 Markdown 编写，语法简单，专注内容创作。

```markdown
# 标题
**粗体** *斜体*
- 列表项 1
- 列表项 2
```

### 响应式布局

完美适配各种设备，无论是电脑、平板还是手机，都能获得良好的阅读体验。

## 代码示例

这里展示一个简单的 JavaScript 函数：

```javascript
function greet(name) {
  return `Hello, ${name}!`;
}

console.log(greet('Annella')); // Hello, Annella!
```

TypeScript 版本：

```typescript
function greet(name: string): string {
  return `Hello, ${name}!`;
}

console.log(greet('Annella'));
```

## 未来计划

在未来，我计划在这个博客上分享：

1. **技术文章** - 前端开发、后端技术、算法学习等
